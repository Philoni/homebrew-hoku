# Homebrew tap for Hoku

[Hoku](https://github.com/Philoni/hoku) is a menu bar app for Philips Hue on macOS 26 or later.

```bash
brew tap philoni/hoku
brew trust philoni/hoku
brew install --cask hoku
```

Update with `brew upgrade --cask hoku`.

Hoku is signed with its own certificate and not notarized by Apple. On first launch: System Settings → Privacy & Security → Open Anyway.

Hoku is an independent open-source project and not affiliated with Signify (Philips Hue).
